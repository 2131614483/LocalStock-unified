# 引擎正确性升级报告（P1 后半，2026-08-26）

> 范围：`engine/backtest_engine.py`（聚宽-local）。纯后端，未触碰任何 UI 工程（desktop/desktop、server/、pages/ 均零改动），不影响另一窗口的 UI 工作。

## 三项升级

### 1. 除息日分红入账
**数学原理**：CSMAR 的 `dretwd`（含分红日收益）与 `dretnd`（不含分红日收益）之差即分红效应：

```
dretwd = (close + div) / prev_close_raw − 1
dretnd = close / prev_close_raw − 1
⇒ div_per_share = prev_close_raw × (dretwd − dretnd)
```

引擎在每日循环中检测持仓股除息事件，按 `每股分红 × 持股数` 现金入账。
- 实证校验：茅台 2023-06-30 反推 25.9096 元/股（真实 25.911，差 0.005%）✓
- E2E 验证：买入茅台穿越除息日 → 日志输出「每股 25.91 元 × 200 股 = 5181.92 元入账」，区间收益 +0.47%（无此机制为 +0.20%）
- 防噪声护栏：单日"分红">股价 30% 视为送转股等非现金事件，忽略

### 2. 涨跌停约束（涨停买不进 / 跌停卖不出）
库内 `limit_up/down` 字段全空，按板块规则从 pre_close 推导：

```
主板（market_type 1/4）: limit = round(pre_close × (1 ± 10%), 2)
创业/科创（16/32）:       limit = round(pre_close × (1 ± 20%), 2)
```

当日收盘价触及涨停价 → 拒绝买入；触及跌停价 → 拒绝卖出，log.warn 记录。
- E2E 验证：动量月调仓两年回测出现 **11 笔涨停拒买**（000032/000628 等），交易数 211→200——这正是真实市场约束，此前回测虚增了涨停股的可成交性
- 已知近似：创业板 2020-08-24 注册制改革前涨跌停为 10%，引擎统一按 20% 处理略宽松，报告中声明

### 3. high/low 用真实值
`load_stock_data` 加载 P1 回填后的 `high_price/low_price`；仍缺的行（北交所/退市尾段）自动回退 close。`attribute_history` 的 `high/low` 字段不再用 close 近似——海龟通道、ATR、布林带类策略从此有真实振幅。

## 兼容性

- 单元测试：分红反推、涨跌停推导、非除息日零事件，全部 PASS

## 对评测的影响

| 此前失真 | 现在 |
|---|---|
| 高股息策略漏记分红（年化低估 0.5~2%） | 分红精确入账 |
| 涨停板可买入（打板策略虚增收益） | 涨停拒买 |
| 跌停可卖出（止损策略虚低回撤） | 跌停拒卖 |
| 技术指标高低价≈close | 真实高低价 |
