量化回测平台 API 接口文档

本文档整理了平台提供的所有 API 接口。

1. 策略管理 API

GET /algorithm/index/list 获取策略列表
GET /algorithm/index/edit?algorithmId={id} 编辑策略

2. 回测管理 API

GET /algorithm/backtest/detail?backtestId={id} 回测详情页面
GET /algorithm/backtest/list?algorithmId={id} 回测列表
GET /algorithm/backtest/buildList?algorithmId={id} 回测构建配置列表

3. 回测数据 API (JSON)

以下是本地服务的 RESTful 数据接口：

GET /api/backtest/:id/summary 回测概要
GET /api/backtest/:id/returns 策略收益
GET /api/backtest/:id/trades 交易详情
GET /api/backtest/:id/positions 每日持仓收益
GET /api/backtest/:id/benchmark 基准收益
GET /api/backtest/:id/logs 日志输出
GET /api/backtest/:id/code 策略代码
GET /api/backtest/:id/export?type=transaction|position|log 导出数据

响应格式

{
    "code": 0,
    "data": { ... },
    "message": "success"
}

4. 模拟交易 API

GET /algorithm/trade/list?process=1 模拟交易列表
POST /algorithm/trade/start 启动模拟交易

5. jqdata Python SDK API

平台提供的本地数据 Python 包，用于获取金融数据：

from jqdata import *

# 获取行情
df = get_price('000001.XSHE', start_date='2023-01-01', end_date='2023-12-31',
               frequency='daily', fields=['open','close','high','low','volume'])

# 获取财务数据
df = get_fundamentals(query(valuation, indicator).filter(...))

# 获取指数成分股
stocks = get_index_stocks('000300.XSHG')

# 获取交易日
dates = get_trade_dates(start_date='2023-01-01', end_date='2023-12-31')
函数说明
get_price()获取历史行情数据
get_fundamentals()获取财务数据
get_trade_dates()获取交易日列表
get_all_securities()获取所有证券信息
get_security_info()获取单个证券详情
get_index_stocks()获取指数成分股
get_industry_stocks()获取行业股票
get_mtss()获取融资融券数据
get_extras()获取额外信息

6. 策略 Python API

平台回测引擎内建 API，用于编写量化策略：

函数/对象说明
initialize(context)初始化函数
handle_data(context, data)每日数据处理
run_daily() / run_weekly() / run_monthly()定时运行
order(security, amount)按股数下单
order_target(security, amount)调整至目标股数
order_value(security, value)按金额下单
order_target_value(security, value)调整至目标金额
context.portfolio投资组合信息
context.portfolio.positions持仓信息
get_current_data()获取当前数据
attribute_history()获取属性历史
set_benchmark()设置基准
set_commission()设置手续费
