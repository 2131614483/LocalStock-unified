# 量化回测平台 · 数据源与同步

## 数据来源（2026-08-12 更新）

| 阶段 | 来源 | 说明 |
|------|------|------|
| 历史全量 | CSMAR（上海对外经贸大学数据库） | 1991-06-01 ~ 2026-06-12 |
| 每日增量（**主**） | **腾讯/新浪**（免费免登录 HTTP，`backfill_daily_tx_sina.py`） | 动态补本地最新之后的缺失交易日 |
| 每日增量（备选） | **baostock**（`update-daily-baostock.py`） | 补 `trade_calendar`/`index_daily`/股票名称口径 |

当前范围：**1991-06-01 ~ 最新交易日**，stock_daily 约 1870 万行。

> **为什么腾讯/新浪为主**：baostock 服务端间歇性故障（2026-08-12 实测：`query_trade_dates` 行迭代无超时永久挂起、`WinError 10057`、login `10002007`），且增量同步 40+ 分钟易被环境限时杀；腾讯/新浪回填全市场仅 ~6 分钟、稳定免登录。排错详见 `GitHub同步排错经验.md` 与 `数据同步排错经验.md`。

## 增量同步工具

| 工具 | 用途 |
|------|------|
| `scripts/backfill_daily_tx_sina.py` | **主**：腾讯/新浪回填 `stock_daily`（腾讯 `fqkline` bfq 不复权 + 新浪 `getKLineData` 兜底；volume 手×100、amount=vol×close 估算、pre_close 逐 K 线更新） |
| `scripts/update-daily-baostock.py` | 备选：baostock 增量，补 `trade_calendar`/`index_daily`/名称（报告 1.1 指数表有数据） |
| `scripts/sync_gui.py` | Tkinter GUI：默认数据源=腾讯/新浪（`--source baostock` 可切回），`--silent` 供计划任务、`--register` 注册任务 |
| `scripts/unified_data_sync.py` | **统一入口**：股票日线同步后自动补齐交易日历、刷新股票日期，并汇总 AI/回测/桌面端共同使用的数据状态 |
| `数据同步.exe`（项目根目录） | 启动器，双击用系统 Python311 打开 GUI（改 sync_gui.py 后需 PyInstaller 重打包） |
| `scripts/baostock_sync.py` | baostock 同步核心库（CLI 与 GUI 共用） |
| `scripts/check_data_fresh.py` | 检查本地最新交易日（数据新鲜度） |
| `scripts/sync_quick.py` | 快速探针（子进程 25s 硬超时），已修两 bug：结论行用 `PROBE_OUT:` 前缀解析（防 baostock login/logout stdout 干扰）、探针查整个区间而非最新单日 |

**运行解释器**：必须用**系统 Python311**（`C:\Users\he\AppData\Local\Programs\Python\Python311\python.exe`），baostock/pandas/tkinter/matplotlib 只装在那里；PATH 里的 `python` 是 hermes venv 无这些库。

## 同步机制要点

- 腾讯/新浪回填：**只补 `stock_daily`**，`INSERT OR IGNORE` 不清库；**不写** `trade_calendar`/`index_daily`（故报告 1.1 指数表为空，用腾讯指数替代）。
- baostock：只 `INSERT OR IGNORE`，断点续传（以 trade_calendar 最后日期为起点）、并发锁 `data/sync.lock`（2h TTL）、socket 30s 超时、数据探针快速退出。
- **baostock 故障应对**：登录/查询反复失败或挂起 → **不要死等**，用腾讯/新浪回填；自动重试驱动示例 `data/sync_retry.sh`（进程级 timeout + 清锁 + 冷却重试 + 断点续传）。
- 运行日志 `data/sync.log`，上次结果 `data/sync_meta.json`。

## 计划任务

- **QuantBacktestDataSync**：每日 18:00，运行 `unified_data_sync.py`；统一更新股票日线、交易日历、股票日期与 AI 数据状态。
- 周末/节假日/数据未发布时自动快速跳过。
- 错过执行时间会自动补跑；最长运行 2 小时；已有同步在运行时不重复启动。
- 用 `数据同步.exe --register` 或 GUI「注册计划任务」按钮（重新）注册。

## 关键约定

- 数据库存纯 6 位代码（`000001`）；策略用带后缀（`000001.XSHE`）；引擎 `.split('.')[0]`
- `dretwd` = 考虑现金红利再投资的日收益率；baostock/腾讯回填段用 close/preclose-1 近似
- **覆盖限制**：baostock 无 B 股（200/900）与北交所（8/4/920）；腾讯回填对 920xxx 等失败自动跳过
- `high/low` 在 baostock 段全 NULL → 技术面图用 close 近似
- 数据导入脚本清空 stock_daily 重建；增量脚本只增不改

## 常见问题

- **服务器端口 3000 EACCES**：Windows 保留端口段（2990-3089）占用。用 `PORT=8080 npm start` 等换端口。
- **GUI/exe 打不开**：确认用系统 Python311 启动（tkinter/baostock 依赖）。
- **推 GitHub 失败**：本机代理是 Clash Verge(mihomo) `127.0.0.1:7897`，且需非沙箱模式；详见 `GitHub同步排错经验.md`。
