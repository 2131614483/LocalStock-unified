# 量化回测平台 · 架构与启动

## 回测链路（核心）

```
前端 main.js
  → POST /api/backtest/:id/run
  → server/index.js 用 execFile('python', [engine/backtest_engine.py, '--code', ...])
  → 引擎读 stock_data.db 执行策略
  → 输出纯 JSON 到 stdout
  → server/db.js saveBacktestResult() 写入 backtest.db
  → 前端刷新图表
```

**关键约束**：
- 引擎 stdout 必须是**纯 JSON**，任何多余 print 都会导致 JSON.parse 失败
- Python 3.8+ 需在 PATH，命令名必须是 `python`
- `/run` 超时 120s、maxBuffer 50MB

## 两个数据库

| 库 | 管理模块 | 作用 | 数据量 |
|----|---------|------|--------|
| `data/backtest.db` | `server/db.js` | 业务库：users/algorithms/backtests/daily_records/trades/positions/logs/backtest_code/benchmark_daily_records，启动自动建表+种子数据 | 小（百级） |
| `data/stock_data.db` | `server/stock-db.js` | 行情库：stocks/stock_daily（1870 万行核心表）/trade_calendar/index_daily/index_info/market_daily/risk_free_rate/财务报表 | 大（千万级） |

## 回测引擎（engine/backtest_engine.py，纯标准库）

- `exec(code_str, env)` 执行策略，`env` 注入平台 API（set_benchmark / run_daily / attribute_history / order_target_value / get_price / log / g / context）
- 策略必须定义 `initialize(context)`；run_daily/weekly/monthly 注册调度
- `SeriesDict`/`Series` 是 pandas 极简替代（仅支持切片、.mean()、len()）
- 指标在 `_calculate_metrics()` 计算，返回结构即后端消费的 JSON

## 启动

```bash
npm install        # 安装依赖
npm start          # 启动服务（默认端口 3000；可用环境变量 PORT 覆盖，如 PORT=8080）
node scripts/test-full.js   # 全量测试（35 项用例）
```

Windows 也可用 `启动.bat`（隔离系统 Node.js，日志写 server.log）。

## 引擎单独调试

```bash
python engine/backtest_engine.py --code "def initialize(context): ..." \
  --start 2026-07-01 --end 2026-08-07 --capital 1000000
```

## 多因子量化体系（2026-08-12 更新）

**双轨架构**：研究管线（`scripts/`，pandas，系统 Python311）做因子发现与组合迭代；生产引擎（`engine/factor_calc_stdlib.py` 纯标准库 + `backtest_engine.py` 跨截面 API）在网页复现。两轨**共用 `scripts/factor_registry.json` 因子定义**，`verify_factor_consistency.py` 校验偏差 ≤0.001。

### 每日选股流水线（图文报告一~十节）

```
数据同步(腾讯/新浪回填, ~6分钟) → daily_stock_pick.py 打分 top-N
  → 报告一~六（市场/方案+因子公式/top50/画像/理由/口径）
  → 七 基本面与估值快照(fetch_fundamental: 腾讯 PE/PB/市值 + CSMAR 财务)
  → 八 技术面图(chart_strategies: 布林带/海龟/当日表现/组合净值 → images/)
  → 九 因子诊断(optimize_factors: 名单追踪/周频IC/月度面板校验)
  → 写入 docs/project-docs/每日选股/ + Obsidian 量化回测平台/每日选股/
  → Claude 追加 十 亮点点评
```

### 关键数据口径

- `mkt_cap_total` 单位**千元**（×1000 转元）；利润表归母净利润 = `B002000101`（非 B002100000）
- 无未来函数三铁律：基本面用「报告期+4 个月滞后」、动量 skip 最近 20 交易日、股票池剔除 ST/涨跌停/次新/B股/北交所/金融股
- 打分先 [1%,99%] 缩尾 → z-score → 乘方向加权求和；缺失因子贡献 0
- 引擎新增 API：`get_all_stocks` / `get_factors` / `get_factor` / `rank_normalize` / `order_target_percent`
- 策略库：`scripts/strategies/`（动量/价值/质量/成长/低波/多因子综合 6 个），`seed_strategies.py` 入库
