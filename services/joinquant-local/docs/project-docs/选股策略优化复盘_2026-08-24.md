# 选股策略优化复盘 · 基于 2026-08-15 ~ 08-24 历史跑批

> 范围：smallcap 方案每日 06:00 自动跑批的完整四步（数据同步 → daily_stock_pick top-50 → fetch_realtime → AI 亮点点评）。
> 数据来源：自动化执行记录（9 次跑批）、各日报告「因子 IC 诊断(8.2)」「月度权重校验(8.3)」、方案回测 `validate_daily_schemes.py`（2018-2026，102 个月）。
> 结论先行：策略**稳健但停滞**——防御价值+低波在 risk-off 日超额显著，但暴露出因子失真、超大盘稀释、IC 反转、排名非确定性四大硬伤，需 P0 修正确性、P1 提 alpha。

## 二、暴露的核心问题

### 问题 1：现金流因子(op_cf_ratio)失真，制造价值陷阱
- 公式 = 经营现金流净额 / 净利润。当净利润趋零或为负时比值爆炸（如 -1839.7%），既不代表「质量」，又因该因子仅权重 0.10 不直接主导，但叠加 bp/ep 极高仍把建筑股推入前 10。
- 技能文档 2026-08-15 已警示：「op_cf_ratio 在净利趋零时爆炸失真，高权重会选出微利股，勿再提高其权重」——但 smallcap 方案仍保留 0.10 权重且**未设下限过滤**，陷阱持续复现。

### 问题 2：超大盘股稀释「小市值增强」
- 中国海油（ln_cap 分位 3%）、中国移动（3%）因巨型 bp/ep 长期在列，与方案名「smallcap / 小市值增强」自相矛盾（ln_cap 权重仅 0.10）。实盘把组合拖向「大蓝筹价值」，偏离小盘弹性定位。

### 问题 3：因子 IC 不稳定，静态权重漂移
- 近 11 周 IC 在反向/中性/有效间反复。当前 smallcap 权重固定，在 IC 反向期（08-15/16/18）显著跑输风格；08-24 仅 bp+低波有效，其余中性——**策略有效性高度依赖「价值+低波占优」的单一定价环境**，一旦风格切到成长小盘即失效（08-15/18 创业板 +1.12%/+3.14% 时组合落后）。

### 问题 4：排名非确定性（可复现性 bug）
- 08-15 三次触发：同数据重跑 `daily_stock_pick.py` 产出**完全不同的 top-10**（欧亚集团/我爱我家/蓝帆医疗…），疑似排序并列破断不稳定。会破坏幂等、导致报告被非确定性覆盖（当日教训：必须用已验证报告、禁止盲目重跑）。

### 问题 5：数据源脆弱
- baostock 增量约 40 分钟且常被环境限时杀、服务端间歇性故障（login 10002007、query_trade_dates 挂起）。腾讯/新浪回填稳定（~6 分钟，321 只北交所 920xxx 失败为预期）。baostock 仅用于补 trade_calendar/index_daily/名称。

### 问题 6：策略换手极低、名单长期不变
- 月度调仓 + 截面稳定 → 名单数周不变。在 IC 反转期无法快速纠偏，回撤暴露慢、纠偏迟。

## 三、优化方案（分优先级）

### P0 — 正确性 & 风控（必须做）
1. **现金流因子稳健化**：对 op_cf_ratio 做缩尾（winsorize 至 [-200%, +500%]），或**直接剔除 op_cf_ratio < -50% 的个股**（价值陷阱硬过滤）——可一次性移除安徽建工/山东路桥类。
2. **排名确定性**：排序改用 `stable sort` + 复合 tie-breaker（综合得分 → 代码），消除 08-15 非确定性，保证幂等可复现。
3. **超大盘过滤 / 升权**：加市值分位上限（剔除 ln_cap 分位 < 10% 的巨无霸），或把 ln_cap 权重上调，让「小市值增强」名副其实。

### P1 — 因子有效性（提升 alpha）
4. **动态 / regime 权重**：用滚动 11 周 IC 做权重缩放（有效因子升权、反向因子降权至 0），至少实现「IC 反向因子置 0」开关，替代固定权重。
5. **采用 lean 式基底 + 实盘约束**：方案回测 `lean`（bp+ep+roe+ln_cap）夏普 +0.24 最高；月度权重校验「当前+小市值0.05」夏普 +0.25 最优。建议新建 `smallcap_lean` 方案：ln_cap 0.25~0.35 + bp0.3 + ep0.15 + roe0.1，剔除毛利/现金流/低波（IC 中性时），并加流动性/涨跌停成本约束。
6. **小市值权重上调**：ln_cap 0.10 → 0.20，强化小盘弹性，契合方案定位。

### P2 — 工程 & 监控
7. **数据源默认腾讯/新浪**：baostock 降级为可选补口径，文档化北交所 920xxx 跳过（321 失败为预期）。
8. **样本外监控告警**：记录「名单等权持有至今 vs 沪深300」滚动超额，设阈值（超额 < -5% 或连续 3 日跑输）触发复核提醒。
9. **月度复核 SOP**：固定每月初用 `validate_daily_schemes` + `research_panel` 复核权重，禁止日更追改（防过拟合）。

## 五、风险与边界
- **lean +67.7% 含小市值容量/流动性/涨跌停成本未计价虚高**，实盘预期应大幅下调；小市值权重 0.35+ 风格集中，建议小仓位试运行、月度复核。
- 任何权重**日更都易过拟合**，坚持月度复核。
- 价值陷阱过滤可能误伤真实困境反转标的（如山东路桥新闻称现金流改善、订单增长），建议过滤后用新闻/订单面二次确认，而非一刀切。
- 排名确定性修复后，需重新跑一遍 08-15 同数据验证 top-10 可复现，避免再次非确定性覆盖。
