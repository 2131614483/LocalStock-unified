# 量化回测平台（聚宽-local）· 项目总览

> 全本地运行的 A 股量化回测平台 + 多因子每日选股体系：数据全部本地存储，外部接口（腾讯/新浪）仅用于每日增量与实时行情。

## 项目定位

- 在网页上编写 Python 策略 → Node.js 后端调用本地 Python 引擎回测 → 结果写入 SQLite → 前端图表展示
- **多因子研究管线**（pandas）→ **生产引擎**（纯标准库）双轨，共用 `factor_registry.json` 因子定义
- **每日选股**：多因子截面打分 → **图文报告（一~十节）** → Obsidian，附基本面/技术面/因子诊断
- 行情数据：CSMAR 全量历史 + **腾讯/新浪每日增量（主）** + baostock（备选）
- 配套工具：Tkinter 同步 GUI、exe 启动器、Windows 计划任务每日自动同步

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 原生 HTML/CSS/JS + Chart.js | 无框架，6 个 Tab 展示回测结果 |
| 后端 | Node.js + Express | 端口 3000，REST API |
| 数据库 | SQLite (better-sqlite3) | 两个库：业务库 + 行情库 |
| 回测引擎 | Python 3（纯标准库） | 执行用户策略代码，本地真实行情 |
| 数据源 | CSMAR + 腾讯/新浪（主）+ baostock（备） | 历史全量 + 每日增量 |
| 每日选股 | Python（factor_calc_stdlib）+ matplotlib + pandas | 打分→图文报告→Obsidian |
| 同步工具 | Tkinter GUI + CLI + exe | 默认腾讯/新浪，可切 baostock |

## 核心功能

1. **在线回测**：网页写策略（`initialize` + 定时调度），本地引擎跑真实 A 股日线
2. **结果可视化**：策略收益 / 交易详情 / 每日持仓 / 基准对比 / 日志 / 策略代码
3. **行情查询**：REST API（个股日线、指数、交易日历、股票搜索、收益率）
4. **多因子量化体系**：研究管线（IC/分层/相关性）→ 因子注册表 → 生产引擎 → 策略库
5. **每日选股**：多因子打分 top-N → 图文报告（因子公式/基本面快照/技术面图/因子诊断/名单追踪）→ Obsidian「量化回测平台/每日选股/」
6. **数据导入与同步**：CSMAR 全量导入（Python 版快 3-5 倍）+ 腾讯/新浪每日增量（主）+ baostock（备）
