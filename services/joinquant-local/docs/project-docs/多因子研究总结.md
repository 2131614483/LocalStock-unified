# 多因子量化研究总结

> 量化回测平台（聚宽-local）多因子体系：研究管线 + 策略库 + 迭代回测
> 生成时间：2026-08-10

## 一、目标与总体设计

用平台积累的 CSMAR 全量数据（1991-2026 A股日线 + 三大财务报表）做**真正的多因子量化研究**：

- **分多个方向**建策略（动量/价值/质量/成长/低波/多因子综合），各自独立评测；
- **自由选股**：不限于固定股票池，每月全市场截面打分选 top-N；
- **反复迭代**：研究管线出因子证据 → 定权重 → 组合回测 → 调参 → web 引擎复现。

**双轨架构**（为什么这样设计）：
| 轨 | 模块 | 作用 | 解释器 |
|----|------|------|--------|
| 研究管线 | `scripts/factor_lib.py` + `factor_research.py` + `multi_factor_backtest.py` | 因子 IC 分析、组合回测迭代，快 | 系统 Python311（pandas） |
| 生产引擎 | `engine/factor_calc_stdlib.py` + `backtest_engine.py` 新增 API | 网页写策略、真实回测、可视化 | PATH python（纯标准库） |

两轨**共用同一份 `factor_registry.json` 因子定义**，且用 `scripts/verify_factor_consistency.py` 强制两轨在抽查日期/因子上因子值偏差 ≤0.001——研究结论能无损落到生产引擎。

## 二、数据基础（实测校验）

| 数据 | 规模 | 用途 |
|------|------|------|
| `stock_daily` 日线 | 1870 万行，1991-2026 | 动量/波动/流动性/市值因子 |
| `fs_comins` 利润表 | 69 万行 | 营收/净利润/EPS |
| `fs_combas` 资产负债表 | 69 万行 | 净资产/总资产/负债 |
| `fs_comscfd` 现金流 | 67 万行 | 经营现金流 |
| `index_daily` 指数 | 9.7 万行 | 基准 000300 |

**关键实证结论**（决定因子口径）：
- CSMAR 科目代码用 平安银行/茅台 2024 年报钉死：利润表 `B001100000`=营业收入、`B002000101`=归母净利润、`B003000000`=EPS；资产负债表 `A001000000`=总资产、`A003100000`=归母净资产。**数据代理/文档里常见的 B002100000 归母映射是错的**。
- `mkt_cap_total` 单位是**千元**（×1000 转元），非万元——用三家真实股本反推实证。
- `stocks.name` 经 baostock 回填；`high/low` 在库中全 NULL（不能用振幅类因子，已移除 `amplitude_20d`）。

## 三、因子库设计（为什么这样写）

`factor_registry.json` 定义约 20 个因子（动量/反转/波动/流动性/技术/规模/价值/质量/成长），每个含方向（+1 越大越好）。

**无未来函数是可信度的根基**（三条铁律）：
1. **基本面点时间对齐**：`declare_date` 92% 为空，改用「报告期 acc_period + 固定 4 个月披露滞后」（年报 4/30、半年报 8/31、三季报 10/31），且 `report_type='A'` 合并报表、排除 `2025-01-01` 这类非季度末异常报告期。
2. **动量 skip 最近 20 交易日**（规避短期反转噪音）；股票池剔除 ST(trade_status!=1)/涨跌停/停牌/次新(<120 交易日)/B 股/北交所/退市。
3. **金融股剔除**：银行/证券/保险的营收成本口径与工商企业不同，污染毛利率/市销率/营收增速，按名称关键词从选股池剔除。
4. **市值 NULL 兜底**：baostock 增量段无市值，用「参考股本 × 当日收盘」推算。

## 四、因子研究结果（2018-2026，102 个月，Rank IC）

| 因子 | 方向 | IC均值 | IC_IR | IC>0比例 | 结论 |
|------|------|--------|-------|----------|------|
| bp（账面市值比） | +1 | 0.0558 | **0.34** | 0.59 | **最稳健有效**，四段市场均正 |
| op_cf_ratio（现金流/利润） | +1 | 0.0157 | **0.34** | 0.67 | 稳健，质量类代表 |
| ep_ttm（盈余收益率） | +1 | 0.0167 | 0.12 | 0.60 | 弱正 |
| ln_cap（规模，-1 小市值） | -1 | -0.0495 | -0.28 | 0.34 | 小市值有效 |
| mom_12m1m / mom_1m（动量） | +1 | -0.024 / -0.064 | -0.15/-0.45 | — | **A股动量反向**（短期反转主导） |
| vol_60d / liq_20d / turnover（高波/高换手） | -1 | -0.086/-0.098/-0.077 | — | — | 低波/低换手有效 |
| rev_growth / profit_growth（成长） | +1 | -0.007/-0.002 | — | 0.42/0.47 | 弱（2018-2026 成长因子不显著） |

**核心发现（与 A 股学术文献一致）**：2018-2026 的 A 股，**价值（bp）+ 现金流质量（op_cf_ratio）最有效**，动量与高波动/高换手因子**方向反转**——这解释了为什么"简单买入强势股"的策略普遍跑输。策略库据此把价值/质量作为核心权重，动量仅作辅助。

## 五、策略库（6 个方向，为何这样写）

统一模板：`initialize` 设基准 000300 / 滑点 0.2% / 印花税+佣金；参数放 `g`；`run_monthly` 每月第 1 个交易日调仓；`rebalance` 内 **get_all_stocks 取全市场 → get_factors 取因子截面 → rank_normalize 逐因子 z-score → 按权重加权 → top-N 等权**；含 8% 个股止损与清仓不在名单持仓。

| 策略 | 因子权重 | 选股数 | 设计理由 |
|------|----------|--------|----------|
| value_v1 价值 | bp 0.6 + ep_ttm 0.4 | 30 | bp 是研究里 IC_IR 最高因子，A股价值长期有效 |
| quality_v1 质量 | roe 0.35 + 毛利率 0.25 + 现金流 0.25 + 低负债 0.15 | 30 | 高质量公司防御性强，现金流过滤财务造假 |
| growth_v1 成长 | 营收增速 0.5 + 净利增速 0.5 | 30 | 进攻型配置，研究显示弱但保留作方向对比 |
| lowvol_v1 低波 | vol_60d 1.0 | 30 | 低波因子 A 股有超额，稳健 |
| momentum_v1 动量 | mom_12m1m 1.0 | 20 | **对照实验**：研究显示动量反向，预期表现差 |
| multifactor_v1 综合 | bp0.3+ep0.2+roe0.15+毛利0.1+现金流0.1+低波0.15 | 50 | 多因子分散单一因子失效风险，降回撤 |

## 六、Web 引擎多因子增强（为什么这样改）

原引擎只能单股 `attribute_history` 取数，**无法跨截面选股**（多因子刚需）。新增：

| API | 作用 |
|-----|------|
| `get_all_stocks(date)` | 全市场可交易股票（带后缀），自动过滤 ST/涨跌停/停牌/次新/B股/北交所/金融股 |
| `get_factors(stocks, factors, date)` | 批量取因子截面 `{stock: {factor: value}}`，一次 SQL 拉全股票历史 |
| `get_factor(stock, factor, date)` | 单股单因子 |
| `rank_normalize(dict)` | 截面 z-score 归一化（含方向），策略打分用 |
| `order_target_percent(stock, pct)` | 按总资产比例下单，等权调仓便捷 |

实现：新增 `engine/factor_calc_stdlib.py`（**纯标准库 sqlite3**，与 pandas 研究管线同一注册表、同一公式）。`verify_factor_consistency.py` 在 4 个日期 × 24 因子上验证两轨偏差 ≤0.001，保证研究→生产无损。

## 七、迭代流程（研究→生产闭环）

```
因子研究(factor_research.py) → IC/分层/相关性/分市场状态 → 有效因子清单
        ↓ 确定权重
组合回测(multi_factor_backtest.py) → 多配置横向对比 → 优胜组合
        ↓ 落库
策略库(seed_strategies.py → backtest.db) → 网页(engine/backtest_engine.py)复现回测
        ↓ 前端可视化
策略列表页 + 回测详情 → 人工判断 → 调参再迭代
```

## 八、数据质量要点（迭代中踩坑修正）

1. `mkt_cap_total` 单位「千元」×1000（曾误当万元，导致 BP 系统性偏小 10 倍）。
2. 财务科目代码经实证钉死（B002000101=归母净利，非文档常见的 B002100000）。
3. 财报「报告期+4 个月滞后」点时间对齐；去年同期用**年份算术**（`P.replace(year-1)`）而非 `timedelta(days=365)`（闰年差一天导致 TTM 匹配失败）。
4. 保留最近 8 期报告做 TTM/成长（4 期不够覆盖去年同期+去年年报）。
5. `high/low` 全 NULL → 移除振幅类因子。
6. 技术因子 pandas 版与 stdlib 版曾因 for-else 缩进/回看窗口边界产生差异，已统一。

## 九、结论与使用方式

**核心结论**：
1. 2018-2026 A 股，**价值（bp）+ 现金流质量（op_cf_ratio）是最稳健的有效因子**，小市值（ln_cap）也有效；动量、高波动、高换手因子**方向反转**。
2. 多因子策略建议以价值/质量为核心权重，动量仅作负向或低配；成长因子在本期不显著，作防御性观察。
3. 双轨（研究 pandas + 引擎 stdlib）因子口径一致（偏差 ≤0.001），研究结论可无损落地 web。

**使用方式**：
- 研究：`python311 scripts/factor_research.py`（出因子报告）；`scripts/multi_factor_backtest.py`（组合对比迭代）。
- 策略：`pages/algorithm-list.html` 列表 → 新建/选择 → `edit.html` 改权重 → 运行回测；或 `scripts/strategies/` 改文件后 `scripts/seed_strategies.py` 入库。
- 引擎新 API：`get_all_stocks` / `get_factors` / `rank_normalize` / `order_target_percent`，见 `docs/strategy-code-standard.md` 多因子章节。

## 十、后续迭代方向

- 因子层面：加 TTM 精度校验、行业中性化、换手率成本敏感性分析。
- 组合层面：调仓频率（月/周）、选股数 N 网格搜索、等权 vs 市值加权、风控（止损/仓位上限）参数化。

## 五之二、策略回测对比（2018-2026 净成本等权月调仓）

> 用研究面板（`scripts/compare_strategies_panel.py`）快速对比，成本=换手×(2×滑点0.2%+2×佣金0.03%+印花税0.1%)。对照：**沪深300 同期总收益 +12.3%**（A股 8.5 年基本走平）。

| 策略 | 总收益 | 年化 | 夏普 | 最大回撤 | 均换手 |
|------|--------|------|------|----------|--------|
| 动量 | **-87.2%** | -21.5% | -0.54 | -87.4% | 40% |
| 价值 | -1.2% | -0.1% | -0.05 | -32.5% | 14% |
| 质量 | -63.4% | -11.2% | -0.49 | -72.4% | 19% |
| 成长 | -3.8% | -0.5% | -0.02 | -56.5% | 12% |
| 低波 | -26.3% | -3.5% | -0.35 | -33.1% | 43% |
| **多因子综合** | **+4.9%** | +0.6% | -0.03 | -27.9% | 17% |

**实证结论（为什么重要）**：
1. **动量 -87% 是最强反面教材**——A 股 2018-2026 动量完全反向，简单"买强势股"爆亏。这解释了散户常踩的坑。
2. **多因子综合是唯一为正**（+4.9%），分散化 + 价值/质量核心权重显著降损（回撤 -28% vs 动量 -87%）。
3. **价值/成长接近平盘**：因子 IC 是"截面相对"有效，但在平市中多头组合净成本收益有限；2018-2026 沪深300 也仅 +12%。
4. 启示：单靠因子选股在平/熊市不够，需叠加**市场择时/仓位管理**（如大盘走弱降仓）与更低的换手成本。这是下一步迭代方向。
