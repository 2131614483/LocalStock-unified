# LocalStock 云端数据来源总览

> 本文汇总**全项目**（桌面端 `apps/desktop` + 聚宽服务 `services/joinquant-local` + `pa-agent`）
> 所有依赖外部网络的云端数据来源，含接口地址、用途、认证方式、引用位置与已知限制。
>
> **分工说明**：行情接口的详细字段解析、本地化流程、下载脚本用法，
> 见 `apps/desktop/docs/下载数据源.md`（桌面端视角）与
> `services/joinquant-local/docs/project-docs/数据源与同步.md`（聚宽侧视角）。
> 本文是**跨模块的横向索引**，不重复上述细节。
>
> 统计口径：全仓 `apps/desktop/electron`、`apps/desktop/src`、`apps/desktop/python`、
> `services/joinquant-local/{scripts,server,engine,api,pages}` 扫描所得，共 **35 个云端主机**。

## 一、数据流总览

```
                    ┌─────────────── 云端接口（免费免登录为主）───────────────┐
                    │  东方财富 push2 / push2his / datacenter / np-*          │
                    │  腾讯   qt.gtimg.cn / ifzq.gtimg.cn / proxy.finance.qq  │
                    │  新浪   hq.sinajs.cn / quotes.sina.cn / feed.mix        │
                    │  baostock（SDK）· CSMAR（离线学术库）                    │
                    └────────────────────────┬───────────────────────────────┘
                                             │ 同步脚本 / 主进程 HTTP
                                             ▼
                            ┌────────────────────────────────┐
                            │  唯一权威行情库                  │
                            │  data/market/stock_data.db     │
                            │  stock_daily / stock_minute /  │
                            │  trade_calendar / stocks /     │
                            │  index_daily                   │
                            └───────────────┬────────────────┘
                                            │ 只读
              ┌─────────────────────────────┼─────────────────────────────┐
              ▼                             ▼                             ▼
     桌面端 Electron 主进程          pa-agent / pa-agent-aggressive    聚宽服务 scripts/
     （本地聚合优先，云端仅回退）      （LocalStockSource，直读本地）      （多因子选股与回测）
              │                             │                             │
              └──────────────┬──────────────┴──────────────┬──────────────┘
                             ▼                             ▼
                    AI 大模型服务                 通知 / 基础设施
              deepseek · opencode · anthropic   飞书 · PushPlus
              openai · xiaomimimo · tencent     清华 PyPI · ghproxy
```

**核心设计**：行情数据以 `stock_data.db` 为唯一权威源，云端接口只在本地缺数据时回退，
因此正常使用**不依赖外部网络**，也不会被免费接口限流影响。

## 二、行情类（免费免登录）

### 2.1 东方财富

| 主机 | 接口路径 | 用途 | 引用位置 |
|---|---|---|---|
| `push2.eastmoney.com` | `/api/qt/ulist.np/get` | 多股/指数**批量实时快照**（主源） | `electron/market/`、`pa_agent/data/eastmoney_client.py` |
| `push2.eastmoney.com` | `/api/qt/clist/get` | 沪深 A 股列表（本地无数据时回退） | `electron/market/` |
| `push2his.eastmoney.com` | `/api/qt/stock/kline/get` | 日/周/月 K 线回退源 | `electron/market/` |
| `push2his.eastmoney.com` | `/api/qt/stock/trends2/get` | 分时回退源 | `electron/market/` |
| `searchapi.eastmoney.com` | `/api/suggest/get?type=14` | 股票**搜索**（代码/名称/拼音 → secid） | `electron/market/eastmoney.ts` |
| `quote.eastmoney.com` | 个股页 / `gridlist.html` | 页面跳转与 Referer | `electron/market/http.ts` |

> `searchapi` 需要携带固定 `token`（`D43BF722C8E33BDC906FB84D85E326E8`）。
> 这是东财公开前端查询 token，**非私人凭据**，硬编码于 `electron/market/eastmoney.ts`。

### 2.2 腾讯

| 主机 | 接口路径 | 用途 | 引用位置 |
|---|---|---|---|
| `qt.gtimg.cn` | `/q={codes}` | **盘口五档 + 涨跌停 + 量比委比**（GBK 编码） | `electron/market/tencent.ts` 等 10 个文件 |
| `web.ifzq.gtimg.cn` | `/appstock/app/fqkline/get` | 前复权日/周/月 K 线 | `sinatencent_source.py`、`backfill_daily_tx_sina.py` |
| `ifzq.gtimg.cn` | `/appstock/app/kline/mkline` | 分钟 K 线 | `electron/market/minute-kline.ts` |
| `proxy.finance.qq.com` | `/ifzqgtimg/appstock/news/info/search` | 个股新闻 | `fetch_news_snapshot.py` 等 |
| `finance.qq.com` / `gu.qq.com` | — | 页面 Referer | — |

> ⚠️ `qt.gtimg.cn` 返回 **GBK**，必须用 `iconv-lite`（Node）/ 显式 decode 处理，
> 否则中文股票名乱码。

### 2.3 新浪

| 主机 | 接口路径 | 用途 | 引用位置 |
|---|---|---|---|
| `quotes.sina.cn` | `/cn/api/jsonp_v2.php/.../CN_MarketDataService.getKLineData?scale=1` | **分时（分钟线）主源**，当天约 238 点 | `electron/market/minute-kline.ts`、`minute-sina.ts` |
| `hq.sinajs.cn` | `/list={codes}` | 实时快照（备用） | `sinatencent_source.py`、`fetch_global.py` |
| `feed.mix.sina.com.cn` | `/api/roll/get?pageid=153&lid=2517` | **全球财经要闻**（要闻快照） | `fetch_global.py`、`fetch_news_snapshot.py`、`fetch_realtime.py` |
| `finance.sina.com.cn` | — | 必须携带 `Referer`，否则被拒 | 多处 |

> ⚠️ `hq.sinajs.cn` 与 `finance.sina.com.cn` 系列**强制校验 Referer**，
> 缺 Referer 直接返回空/403。代码中已统一加 `_SINA_QUOTE_HEADERS`。

### 2.4 baostock（SDK，非 HTTP）

| 项 | 说明 |
|---|---|
| 入口 | `baostock.com`，通过 `baostock` Python 包访问（内部走自有 socket 协议） |
| 用途 | **备选**数据源：补 `trade_calendar` / `index_daily` / 股票名称口径 |
| 认证 | 无需账号密码，但**必须显式 `login()` / `logout()`** |
| 引用 | `pa_agent/data/baostock_source.py`、`baostock_sync.py`、`update-daily-baostock.py` |

> ⚠️ **已知故障**（2026-08-12 实测）：服务端间歇性不可用——
> `query_trade_dates` 行迭代无超时永久挂起、`WinError 10057`、`login 10002007`；
> 且增量同步 40+ 分钟易被环境限时中断。
> **因此日常增量主源是腾讯/新浪**（全市场回填仅约 6 分钟，稳定免登录）。
> 排错记录见 `services/joinquant-local/docs/project-docs/数据同步排错经验.md`。

### 2.5 CSMAR（离线学术库，非 API）

| 项 | 说明 |
|---|---|
| 来源 | CSMAR（**上海对外经贸大学**校级数据库） |
| 覆盖 | 1991-06-01 ~ 2026-06-12 历史全量 |
| 方式 | **离线导出后导入**，不是在线接口，无网络依赖 |
| 现状 | 当前库范围 1991-06-01 ~ 最新交易日，`stock_daily` 约 1,870 万行 |

| 主机 | 用途 | 引用位置 |

> `electron/pa/runtime.ts` 的 Python 环境准备优先级：
> ① 已有健康 venv（零下载）→ ② 设置里的 `pythonPath` → 随程序分发的 runtime
> → 本机 Python 官方安装目录 → PATH → ③ 全都没有才从 GitHub 下载独立 CPython。

## 七、限流、封禁与容错

| 限制 | 现象 | 项目对策 |
|---|---|---|
| 东财限流 | 高频请求封 IP（HTTP 000） | 主进程**串行节流**（`Limiter`）+ 本地化 + **60s 冷却回退** |
| 新浪 Referer 校验 | 缺 Referer 返回空 | 统一 `_SINA_QUOTE_HEADERS`，带 `finance.sina.com.cn` |
| 腾讯 GBK 编码 | 中文股票名乱码 | `iconv-lite` 解码 |
| baostock 不稳定 | 挂起 / `WinError 10057` / login 失败 | 降级为备选源，主源改腾讯/新浪 |
| 新浪分钟线仅约 5 天 | 历史分钟缺失 | 分时只需当天，够用 |
| 退市股缺失 | 新浪源只含现存股票（**幸存者偏差**） | 长周期回测收益偏高；近 3-5 年影响小；Tushare 可补 |
| 换手率 / 市盈率 | 本地列表无此字段 | 显示 `--`，可用东财补充 |

## 九、如何新增一个数据源

1. **优先判断能否本地化**：若 `stock_data.db` 已有该数据，直接读库，不要新增云端调用。
2. **新增适配器**：在 `pa_agent/data/` 下实现并继承 `data/base.py` 的接口。
3. **注册 provider**：在 `pa_agent/config/settings.py` 的 provider 白名单中加入名称
   （如 `tushare` 已注册但默认不启用）。
4. **若为 Python 依赖**：写进对应 `requirements.txt`，但**默认注释掉**——
   服务端只装必需项，避免拖慢 venv 创建（见 `pa-agent/requirements.txt` 说明）。
5. **补监控与回退**：必须实现失败回退，参照现有「东财 → 腾讯」的 60s 冷却模式。
6. **加 Referer / 编码处理**：新浪系要 Referer，腾讯 `qt.gtimg.cn` 要 GBK 解码。
7. **更新本文档**：把新主机、端点和引用位置登记到上表。
