# LocalStock 桌面便携版

本地自用的 A 股行情 + 量化回测工具（同花顺风格）：指数、自选股、K线/分时、盘口五档、搜索、回测。免登录、免数据库服务，数据全部存本地 SQLite。

## 功能

- **行情浏览**：顶部指数栏（上证/深成/创业板/沪深300/科创50）、自选股表格（红涨绿跌、列排序、实时刷新）、沪深A股列表、个股详情（报价头 12 项指标 + 分时图 + 日/周/月 K 线 + 盘口五档 + 涨跌停）
- **K线画线**：日K 上图可手动画线（趋势线/水平线/射线/矩形/斐波那契/通道，选色/删除/清空）、**Python 算法画线**（写脚本生成支撑压力线等）、**自动版本历史**（每次画线存版本，可跳转恢复）、画线持久化保存
- **搜索**：按代码/名称/拼音实时搜索
- **AI 全接入**：AI 可读全部行情/自选/K线/分时/盘口/本地库（只读），可写**量化策略 / K线画线 / 自动选股**三类（写操作审计可一键回滚）；支持 Anthropic / OpenCode Go / DeepSeek / Ollama 多后端，⚙ 面板一键配置（粘贴 `provider:sk-xxx`）
- **自动选股**：规则引擎（技术面全市场扫描 + 基本面快照，可定时）与 AI 动态双模式；结果可加自选/跳详情/一键回测
- **实时监盘 + AI 预测**：独立监盘窗口（单例复用，置顶/半透明/大屏），实时行情入库、定时+异动触发 AI 实时预测、命中率统计（总览/按股票/按小时），15:00 收盘感知；间隔 5s~5min 可调
- **分时 AI 预测画线**：分时图右侧约半宽面板，AI 画支撑压力/预测收盘/剩余走势/次日（标注可删/清空/对话）
- **视图浮窗 + 分栏缩放**：「🗔 窗口」把任意视图拆成独立系统窗口自由排布；应用内所有分栏（侧栏/盘口/模板/AI面板/监盘表格）可拖拽改宽；K线图支持拖高 + 主图/副图分割 + **随窗口等比例缩放**（含回测结果图）
- **集中设置页**：侧边栏「设置」统一配置行情/图表/AI 后端/监盘/回测/数据，也可拆成独立窗口
- **指数 K 线**：上证/深成/创业板/沪深300/科创50 支持在线完整蜡烛 + 本地 close 线回退；指数分时东财优先
- **量化回测**：策略代码编辑器（**自动保存**、**复原按钮**）+ 4 个内置模板（买入持有/双均线/布林带/海龟），**个股详情页可直接跳转回测**并自动填入股票池，运行后展示指标卡、收益曲线（vs 基准）、回撤、交易记录、持仓、日志
- **数据管理**：回测页一键下载全量 A 股历史日线（断点续传、进度可见）

## 交付物（dist 目录，组合模式）

| 包 | 大小 | 内容 |
|---|---|---|
| **LocalStock-app.zip** | ~158MB | 软件代码（解压得到 win-unpacked 文件夹） |
| **LocalStock-data.zip** | ~761MB | 行情数据包（解压得到 `data` 文件夹，含 5,206 只股票 1,644 万行日线） |

**组合使用**：
1. 解压 `LocalStock-app.zip` → 得到 `win-unpacked` 文件夹
2. 解压 `LocalStock-data.zip` → 得到 `data` 文件夹
3. 把 `data` 文件夹放进 `win-unpacked` 目录（`win-unpacked\data\stock_data.db`）
4. 双击 `win-unpacked\LocalStock.exe` → 行情库就绪

> 未放数据也能打开软件：回测页会提示"未检测到数据"，可点"下载数据"（约 1.5-2 小时）或按提示放置数据文件。

## 数据源架构

| 数据 | 来源（按优先级） | 说明 |
|---|---|---|
| 实时快照 | 东方财富 → 腾讯（60s 冷却回退） | 指数/自选/详情报价 |
| **日/周/月 K 线** | **本地 SQLite**（前复权日线聚合）→ 东财 | 本地化，不受接口限流影响 |
| **分时** | **新浪分钟线**（免费稳定）→ 东财 | 当天逐分钟，均价由累计量额计算，**持久化写入本地库 `stock_minute` 表**（下次直接读库） |
| 盘口五档 + 涨跌停 | 腾讯 qt.gtimg.cn | GBK 编码 |
| 搜索 | 东方财富 searchapi | 代码/名称/拼音 |
| 回测历史日线 | AkShare（新浪源）下载 → 本地 SQLite | 全量前复权 |

所有行情请求经主进程串行节流 + 本地缓存，避免触发免费接口限流。

## 回测功能

侧边栏"回测"页使用。数据就绪后即可编写/选择策略并运行：

- **策略 API**：`initialize(context)`、`g`、`run_daily`、`order_target_value`、`attribute_history`、`log` 等
- **前置依赖**：本机需 Python 3.9+ 与 AkShare：
  ```bash
  pip install akshare pandas
  ```
- **注意**：策略内用 `log()` 而非 `print()`，否则会破坏回测输出 JSON

## 数据存储（全部 SQLite）

- **回测行情库** `stock_data.db`（3GB）：`stock_daily`/`trade_calendar`/`stocks`/`index_daily`/`stock_minute`（分时持久化）表，位于软件 `data\` 目录（或 `%APPDATA%`）
- **应用业务库** `localstock.db`：自选股、设置、K线/分时缓存，位于 `%APPDATA%\localstock-desktop\`

## 开发

```bash
npm install          # 含 better-sqlite3 针对 Electron 的 rebuild
npm run dev          # 开发运行
npm run build        # 构建（产物 out/）
npm run build:win    # 打包（electron-builder portable）
npm run typecheck    # 类型检查
npm run gen-icon     # 重新生成图标
```

## 通达信备选数据

分时数据备选方案曾考虑通达信：其数据存于本地客户端（`vipdoc\...\minline\*.lc1` 分钟文件）。**需本机安装通达信客户端才有这些文件**（本机未安装）。若日后安装，可加"从通达信本地数据读取分时"模块补充。

## 注意

- 所有数据源为免费接口，可能有限流或延迟，仅供本地参考，不构成投资建议
- 行情库不含退市股票（幸存者偏差），长周期回测收益会偏高；近 3-5 年回测影响小
- 深色主题、红涨绿跌（A股配色）
