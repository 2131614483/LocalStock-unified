# ==============================================================================
# apps/desktop/python/engine —— 回测与画线引擎依赖
# ------------------------------------------------------------------------------
# 适用范围：backtest_engine.py、draw_engine.py
#
# ✅ 结论：**无第三方依赖，纯标准库实现。**
#    本文件存在的意义是显式记录这一事实，避免后续有人误加依赖，
#    也让 `pip install -r requirements.txt` 可以安全空跑。
#
# 实际使用到的标准库：
#   argparse    命令行参数解析（两个引擎都由 Electron 主进程以子进程方式调用）
#   sqlite3     直接读 LocalStock 统一行情库 data/market/stock_data.db
#   json        与主进程交换 K 线数据与画线结果的协议格式
#   collections / datetime / os / sys / traceback
#
# 调用方式（由主进程拉起，非独立服务）：
#   python backtest_engine.py ...   回测计算
#   python draw_engine.py --code <算法代码> --data <K线JSON文件>
#
# ---------- 设计约束（请勿破坏）----------
# 1) 引擎必须保持零第三方依赖：它在 Electron 子进程里被反复拉起，
#    额外依赖会拖慢冷启动，也增加打包体积。
# 2) 算法通过注入的方式提供（data / n / draw_line / draw_ray / draw_hline /
#    draw_rect / draw_fib / draw_channel / log），策略代码不需要 import 任何包。
# 3) draw_engine.py 中算法内禁用 print()——会污染 JSON 输出，需用 log() 代替。
