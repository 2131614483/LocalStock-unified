# LocalStock 桌面版 — 数据源与下载

> 本地自用的 A 股行情 + 量化回测工具。数据全部存本地 SQLite，免费数据源，无外部网络依赖。

## 一、数据源总览

| 数据类别 | 来源（优先级） | 获取方式 | 本地化策略 |
|---|---|---|---|
| 实时快照（指数/自选/报价） | 东方财富 → 腾讯 | 主进程 HTTP，串行节流 | 内存缓存，60s 冷却回退 |
| 日/周/月 K 线 | **本地库聚合** → 东财 | 本地 SQLite 查询 | ✅ 本地（前复权日线聚合） |
| 分时 | **新浪分钟线** → 东财 | 主进程 HTTP | ✅ 持久化入库 `stock_minute` |
| 盘口五档 + 涨跌停 | 腾讯 qt.gtimg.cn | 主进程 HTTP（GBK 解码） | 实时，60s 冷却回退 |
| 搜索 | 东方财富 searchapi | 主进程 HTTP | 无 |
| 沪深A股列表 | **本地库生成** → 东财 | 本地 SQLite 查询 | ✅ 本地（每只最新日线） |
| 回测历史日线 | AkShare（新浪源） | Python 下载脚本 | ✅ 本地 SQLite 全量 |

## 二、行情数据源详情

### 1. 实时快照
- **东方财富** `push2.eastmoney.com/api/qt/ulist.np/get`：多股/指数批量快照（现价/涨跌幅/量/额等）
- **腾讯** `qt.gtimg.cn/q=`：快照回退源，含盘口
- 东财失败自动切腾讯（60s 冷却，避免反复试探被封接口）

### 2. 日/周/月 K 线（本地化）
- **本地 `stock_data.db` 的 `stock_daily` 表**（前复权日线，1,644 万行）
- 日 K：直接读；周/月 K：按周/月聚合（open=首日开、close=末日收、high/low=max/min、量额=sum）
- 本地无数据时回退东财 `push2his/stock/kline/get`

### 3. 分时（新浪分钟，持久化）
- **新浪** `quotes.sina.cn/.../getKLineData?scale=1`：当天逐分钟（约 238 点）
- 均价 = 累计成交额 / 累计成交量（volume 股、amount 元，已验证一致）
- **拉取后写入本地 `stock_minute` 表**，下次直接读库
- 回退东财 `trends2`

### 4. 盘口五档
- **腾讯** `qt.gtimg.cn/q=`（GBK 编码，iconv-lite 解码）：买卖五档、涨跌停价、量比、委比、市值

### 5. 搜索
- **东方财富** `searchapi.eastmoney.com/api/suggest/get`：按代码/名称/拼音，返回 secid

### 6. 沪深A股列表（本地化）
- **本地 `stock_data.db`**：`stock_daily` 每只股票最新日线 + `stocks` 表名称
- 支持按涨跌幅/现价/成交量/成交额等排序、分页
- 本地无数据时回退东财 `clist`

## 三、回测数据（历史日线全量下载）

### 数据源
**AkShare（新浪源）** 免费免注册。曾实测 Baostock 在本机网络极慢/卡死（单只 >120s），故弃用。

### 下载脚本
`python/scripts/download_full_data.py`：
- 全 A 股（沪深，~5,206 只）× 1990~最新 **前复权日线**
- 建表 `stock_daily`/`trade_calendar`/`stocks`/`index_daily`
- 断点续传（已有数据跳过）、进度 JSONL 输出
- 全量约 1.5-2 小时

### 下载方式
1. **应用内**：回测页 → "下载数据"（进度可见、可断点续传）
2. **数据包**：`LocalStock-data.zip` 解压得到 `data` 文件夹放软件旁

### 数据库结构（`stock_data.db`）
| 表 | 内容 | 规模 |
|---|---|---|
| `stock_daily` | 前复权日线（open/high/low/close/pre_close/volume/amount/dretwd/adj_close_wd） | 1,644 万行 |
| `stock_minute` | 分时持久化（当日逐分钟） | 按需累积 |
| `trade_calendar` | 交易日历 | 8,797 天 |
| `stocks` | 股票列表（代码/名称/市场类型） | 5,206 只 |
| `index_daily` | 指数日线（沪深300 等） | 27,203 行 |

- ✅ 日/周/月 K 线：本地库聚合，不受接口限流影响
- ✅ 分时：新浪分钟 → 持久化入库

## 五、数据源限制与备选

| 限制 | 说明 | 对策 |
|---|---|---|
| 东财限流 | 高频请求封 IP（HTTP 000） | 串行节流 + 本地化 + 60s 冷却回退 |
| 退市股缺失 | 新浪源只含现存股票（幸存者偏差） | 长周期回测收益偏高；近 3-5 年影响小；Tushare 可补 |
| 通达信备选 | 分时备选曾考虑通达信，需安装客户端才有本地 `.lc1` 分钟文件 | 本机未安装，新浪已为主源 |
| 分钟历史有限 | 新浪分钟仅最近约 5 天 | 分时仅需当天，够用 |
| 换手率/市盈率 | 本地列表无此字段 | 显示 `--`，可用东财补充 |

## 六、补充说明

- 回测引擎：quant-backtest 的 Python 引擎（`python/engine/backtest_engine.py`），Electron 主进程子进程调用
- 所有行情请求经主进程串行节流（`Limiter`），避免触发免费接口限流
- 数据仅供本地参考，不构成投资建议
