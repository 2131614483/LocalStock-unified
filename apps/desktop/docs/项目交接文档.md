# LocalStock 桌面版 · 项目交接文档

> 本文件是给**另一个 AI/开发者**的完整交接文档，假设读者零上下文。请通读后再动代码。
> 仓库根 `CLAUDE.md` 管统一工作区；**桌面版请以 `apps/desktop/CLAUDE.md` + 本文件为准**。

---

## 0. 项目一句话

**本地自用的 A 股行情 + 量化回测 + AI 智能分析 桌面工具**（同花顺风格、深色主题、红涨绿跌）。Electron 单机应用，无后端、无登录，数据全存本地 SQLite；AI 可只读全部行情数据、可写三类（量化策略 / K线画线 / 自动选股），写操作有审计可回滚。

## 2. 进程与数据流

```
渲染层(主窗/监盘窗/浮窗) ── window.api（preload contextBridge）── IPC(domain:method) ── 主进程
主进程 = 数据中枢：行情拉取/缓存/worker 查询/SQLite/Python 子进程/AI agent
SQLite：localstock.db(业务) + stock_data.db(行情库)
主→渲染推送：market:quotes(广播) / backtest:downloadProgress / ai:chunk|tool|refresh|error|done /
             minute:annotations / monitor:quotes|event|config|stats / float:changed
```

**新增任何 IPC 都要三处同步改**：`shared/types.ts` 的 `WindowApi` + `electron/preload.ts` + `electron/ipc.ts`(或对应域 handler)。

## 3. 数据库

### localstock.db（`app.getPath('userData')`，迁移 runner 管 schema，现 v7）
`watchlist` / `settings` / `kline_cache` / `drawings` / `drawing_history`（每股 100 版）/ `alert_rules` / `alert_events` / `ai_audit`（AI 写审计，可回滚）/ `selection_rules` / `selection_results` / `quote_history`（实时行情入库）/ `monitor_list` / `monitor_events` / `ai_predictions` / `prediction_history`（AI 预测命中率）/ `monitor_state`（预警去重跨重启）。

### stock_data.db（`stockDataPath()`：exe 旁 `data/` 优先，否则 userData）
由 Python 下载产出：`stocks` / `stock_daily`（日线，含 OHLC/量额/前复权）/ `trade_calendar` / `index_daily`（**只存 close**）/ `stock_minute`（分时持久化）/ `stock_minute_kline` / `sync_state` / `sync_meta`。
- 查询走 **worker 线程**（`market/sqlite-worker.ts`，`getKline/getMarketList/getPreClose/runSelection/scanAllMarket`），避免阻塞主进程。
- 主进程解析好路径注入 `db-path.ts`；**worker 内禁止 `require('electron')`**。
- 分时/分钟K可写（`minute-local.ts` / `minute-kline-local.ts`），其余只读。

## 4. 行情数据源（优先级链）

| 数据 | 链 |
|---|---|
| 实时快照 | 东财 push2 →(60s 冷却) 腾讯 qt.gtimg.cn(GBK) |
| 日/周/月/季 K | 本地 stock_daily(worker) → kline_cache → 东财 push2his |
| 分钟K 1/5/15/30/60/120 | 新浪 scale → 腾讯 mkline（120 由 60 聚合） |
| 分时 | 60s 缓存 → 本地 stock_minute → 新浪 scale=1 → 东财 trends2 |
| **指数 K/分时** | **在线东财优先**（完整 OHLC），本地 index_daily(close) 回退；分时东财优先 |
| 盘口五档 | 腾讯(GBK, iconv-lite) |
| 搜索 | 东财 searchapi |

所有出站请求过全局串行 `Limiter`（250ms 最小间隔，队列>200 丢最旧）；`http.ts` 原生 node:https 强制 IPv4。
**指数识别**：`isIndexSecid`（沪 `1.000xxx`/深 `0.399xxx`）——指数**绝不能**走 `stock_daily`（`000001` 会撞平安银行）。

## 5. 功能模块速览

- **自选/沪深**：`views/WatchlistView.tsx` / `MarketView.tsx`（主窗+浮窗共用）；列表本地排序。
- **个股详情** `StockDetail.tsx`：报价头 + 盘口 + 分时/日周月季K + 画线 + AI 分时预测面板。
- **K线画线**：手动（6 种工具）+ Python 算法 + AI `draw_lines`；版本历史/回收站。
- **回测**：策略编辑器（自动保存到 `settings.backtest.code`）+ 模板 + 结果指标/曲线/交易/持仓/日志。
- **AI**：见 §6。
- **自动选股** `selection/`：结构化规则（技术面 worker 全市场扫 + 基本面快照）+ AI 动态模式；结果可加自选/跳详情/回测。
- **实时监盘** `monitor/`：实时行情入库 + 定时/异动 AI 预测 + 命中率统计 + 独立窗口（置顶/半透明/大屏）。
- **分时 AI 预测** `minute-ai.ts`：右侧面板画支撑压力/预测收盘/次日；标注会话内存；预测入监盘统计。
- **视图浮窗** `windows.ts`：任意视图拆独立系统窗口（单例复用），「🗔 窗口」菜单管理。
- **设置页** `SettingsPage`：集中配置行情/AI/监盘/回测/数据，也可浮窗。
- **窗口缩放**：OS 窗口（resizable）；`SplitPane` 分栏拖拽（col/row-resize 光标）；`ResizableChartShell` 图表高度把手；`StockDetail` K线高度+主图/副图分割+**随窗口等比例缩放**（ResizeObserver+宽高比）。

## 6. AI 子系统（重点）

### 架构
```
ai/provider.ts       Provider 抽象：anthropic + openai兼容（OpenCode Go/DeepSeek/Ollama）
ai/agent.ts          agent 工具循环（单会话、流式、超时、并发单飞）
ai/tools.ts          工具注册表（只读 read / 写 write）
ai/tools-write.ts    写：策略/画线/分时标注
ai/tools-selection.ts 写：选股规则/结果/自选
ai/write-gate.ts     写门控（auto/confirm）+ 审计
ai/audit.ts + rollback.ts + rollback-handlers.ts  写审计 + 一键回滚
ai/query-db.ts       只读 SQL 万能钥匙（SELECT-only、行/时上限、schema 提示）
```
- **权限契约**：只读=全部行情/K线/分时/盘口/自选/画线/策略/预警/本地库；写=仅 **策略 / 画线 / 选股** 三类；自选默认只读（`allowWatchlistWrite` 开关）。
- **配置**（`settings` 表 `ai.*`）：`provider/apiKey/model/baseUrl/writeMode`。UI ⚙ 面板有一键配置：粘贴 `provider:sk-xxx`（`opencode-go:`/`deepseek:`/`anthropic:`/`openai:`）自动填 baseUrl+model+key（`src/lib/ai-config.ts`）。
- **当前后端**：OpenCode Go（`https://opencode.ai/zen/go/v1`，model `deepseek-v4-flash`，key 是 OpenCode Zen Go 密钥）。
- **AI 写**：写工具走 `beginWrite` → 审计（含回滚快照）→ 执行 → `ai:refresh` 推送让渲染刷新；回滚在「◷ 最近 AI 操作」里一键。
- **监盘 AI 预测**（`monitor/predict.ts`）：单次结构化 JSON 调用（不走工具循环，提速），定时+异动触发，`prediction_history` 判命中率（up>+0.3%/down<-0.3%/flat±0.5%）。
- **分时 AI 预测**（`minute-ai.ts`）：主进程预计算特征 → DeepSeek 单次调用 → 标注（x=每日分钟序号 0..239，跳过午休）+ 观点；`minute_analyze`(读) + `apply_minute_annotations`(写，审计可回滚)。

### DeepSeek 推理模型铁律
- `deepseek-v4-flash` 是推理模型：`reasoning_content` 计入 `max_tokens` → agent 默认上限 **8000**。
- **不要用 `response_format: json_object`**（reasoning 翻 5 倍更慢更贵，max_tokens 不足时 content 为空）→ 用严格提示词「只输出 JSON」+ 鲁棒提取（`extractJson`：首 `{` 到末 `}`）。
- 多轮工具调用无需回传 `reasoning_content`。

## 7. Python 子进程

- **回测** `backtest:run`：`execFile(backtest_engine.py --code --db --start --end --capital)`，stdout 单 JSON，maxBuffer 50MB/timeout 120s。策略 API：`initialize/g/run_daily/order_target_value/attribute_history/log`。**禁用 print()，用 log()**。
- **画线算法** `drawings:runAlgo`：K线写临时 JSON → `draw_engine.py --code --data` → 单行 JSON `{code,drawings}`。注入 `draw_line/draw_ray/draw_hline/draw_rect/draw_fib/draw_channel`。
- **下载** `backtest:downloadData`：`download_full_data.py`，stdout 逐行 JSONL 进度。
- Python 路径：打包 `resources/python`，开发 `app.getPath('app')/python`；解释器 `settings.pythonPath` 默认 `python`；子进程设 `PYTHONUTF8=1`，脚本内 `reconfigure(utf-8)` 双保险。

## 9. 关键坑（浓缩）

1. **Electron 窗口销毁**：任何 `X?.webContents.send()` 都要判 `isDestroyed()`（`?.` 不挡已销毁实例）——`float:changed` 曾崩。
2. **DeepSeek 推理模型**：见 §6 铁律；max_tokens 要 8000。
3. **query_db**：AI 会猜错表字段 → 工具描述写 schema + 失败提示表结构（`buildSchemaHint`）。
4. **A股 secid 撞码**：`000001` 既是上证指数也是平安银行 → 指数走 `isIndexSecid`，绝不停留在 stock_daily。
5. **SplitPane 网格**：交叉轴必须 `minmax(0,1fr)`，否则图表 `height:100%` 不解析、canvas 溢出。
6. **叠在 canvas 上的拖拽把手不可靠** → 放画布外独立块。
7. **better-sqlite3 是 Electron ABI**：node vitest 无法加载 → 单测用 `vi.hoisted` + 假 db 替身。
8. **构建 EBUSY**：残留 LocalStock.exe 锁 `dist/win-unpacked` → `taskkill /F /IM LocalStock.exe` 后重建。
9. **等比例缩放**：JS clamp 与 CSS min-height 要一致，否则窄窗口打断比例。

## 10. 给接手 AI 的启动指引

1. 先读 `apps/desktop/CLAUDE.md` + 本文件；视觉测试/UI 改动按桌面端文档中的视觉测试要求执行。
2. `npm install`（postinstall 会 rebuild better-sqlite3）→ `npm run typecheck` → `npm run build:win` → 跑相关视觉测试。
3. 涉及 AI：确认 `LOCALSTOCK_DS_*` 环境变量与当前后端（OpenCode Go）；改模型参数按 §6 铁律。
4. 涉及多窗口/推送：改 `shared/types.ts` + `preload.ts` + `ipc.ts` 三处；推送发到 `event.sender`（浮窗）或广播。
5. 涉及布局/缩放：复用 `SplitPane` / `ResizableChartShell` / `StockDetail` 的图表高度+等比例模式。
6. 成功后按习惯把 现象→根因→修复→验证→反思 追加进 `docs/踩坑记录.md`（若当时 Obsidian Vault 存在，也同步一份到 `Documents/Obsidian Vault/LocalStock/开发踩坑记录.md`）。
